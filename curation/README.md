# Xiaohongshu Outdoor Prompt Curation

This folder tracks manually reviewed Xiaohongshu prompt candidates before they are rewritten into product-ready prompt records.

## Policy

- Review sources manually and sequentially; do not scrape aggressively.
- Keep source URL, title, author, category, tags, and curation notes.
- Avoid copying long third-party prompt text into the library verbatim.
- Convert accepted candidates into official `prompts/*.json` entries only after rewriting, deduplication, and asset selection.

## Current Batch

- Topic: outdoor, travel, hiking, landscape, and travel-photo remix prompts.
- Target size: 20 accepted candidates.
- Source file: `xiaohongshu-outdoor-candidates.json`.
